# telar-updates

Repositorio técnico de Telar: aquí se publican únicamente las actualizaciones firmadas
y la lista de licencias retiradas que la aplicación consulta por internet.

- No contiene código fuente de Telar.
- `update.json` y `revocaciones.json` van firmados con la clave privada del vendedor;
  la app rechaza cualquier archivo que no esté firmado correctamente.
- El instalador se publica en la sección "Releases" de este repositorio.
